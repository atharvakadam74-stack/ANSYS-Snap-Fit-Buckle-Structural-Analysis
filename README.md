# ANSYS-Snap-Fit-Buckle-Structural-Analysis
Finite Element Analysis of a Snap Fit Buckle using ANSYS Mechanical to evaluate deformation, stress distribution, and structural integrity during assembly.

## Overview

This project presents a nonlinear structural finite element analysis of a plastic snap-fit buckle using ANSYS Mechanical.

The objective is to evaluate deformation, stress concentration, strain distribution, and structural performance during snap-fit engagement.

---

## Objectives

- Simulate snap-fit assembly
- Evaluate deformation during insertion
- Identify stress concentration regions
- Analyze strain distribution
- Assess structural integrity
- Validate snap-fit performance

---

## Software Used

- ANSYS Workbench
- ANSYS Mechanical

---

## Analysis Type

- Static Structural
- Nonlinear Contact Analysis
- Large Deflection
- Elastic Material Model (or Plastic Material Model if used)

---

## Model Components

- Male Snap Feature
- Female Buckle Housing
- Contact Interfaces

---

## Boundary Conditions

- Fixed support applied to housing
- Displacement applied to snap arm
- Contact interactions between components
- Large Deflection enabled

---

The simulation demonstrates:

- Snap-fit deformation
